About Unsolved Case

What this is: a free, playable web detective game — Season 1, six cases, PeerJS co-op, TTS voices, WebAudio score. No install.

Honest scope: this web build has no native Unity APK/IPA, no real voice chat (use Discord/phone), no server-side anti-cheat and no Firebase/Nakama backend. Solutions live in the case data on your device, so a determined player could peek — that's a web limitation, not a server game. A future Unity/Nakama build would be needed for native apps, server-authoritative play and real voice.

Free-only: no payments, no ads, no hint packs. All 6 cases free in this build.

Content: 16+, fictional crime with restraint, no graphic gore, no violence against children.
